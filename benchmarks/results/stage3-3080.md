# 阶段 3 验收（2026-10-09）

自写 Qwen2，attention 按 block table 读写分页 KV。fp32 验收走 PyTorch 索引；延迟验收走 `DISTIE_ATTN=flash`（`flash_attn_with_kvcache`，页大小 256），decode 一步录成 CUDA graph。

环境：WSL2，RTX 3080 Laptop 16 GB，Qwen2.5-1.5B-Instruct，torch 2.14.1+cu130，CUDA 13.0，flash-attn 2.8.3。

## 正确性

| 报告 | 精度 | 后端 | 结果 |
|------|------|------|------|
| `correctness-fp32-cuda.json` | fp32 | torch 索引 | 8/8 与 HF 贪心逐 token 一致，logits 最大绝对误差 4.2e-5 |
| `correctness-fp16.json` | fp16 | torch 索引 | 8/8 逐 token 一致，logits 最大绝对误差 7.0e-2 |

Mac CPU fp32 仍在 `correctness-fp32.json`。

## batch=1 decode

`decode-latency-3080.json`：同一条 46 token 的 prompt，两边都贪心生成 64 个 token（预热 2 次，测 5 次，取 TPOT 中位数那一次）。生成的 token 一致。

| 路径 | TTFT | TPOT |
|------|------|------|
| HF `generate` | 27.5 ms | 18.1 ms |
| flash + CUDA graph | 29.6 ms | 12.2 ms |

TPOT 是第一个 token 之后、相邻 token 的平均间隔。flash 的五次 TPOT 都在 12.1–12.4 ms。prefill 没有进 graph，所以 TTFT 略高于 HF。
